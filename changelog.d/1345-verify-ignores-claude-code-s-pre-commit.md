kind: Fixed

**`/verify` ignores Claude Code's pre-commit nudge (#1345).** Claude Code ≥ 2.1.286 tells Claude to run any project skill named `verify` before committing, and Sequant ships one that expects an issue number and posts to GitHub. `/verify` now returns a one-line no-op, with no command, comment or question, when a Sequant phase other than verify calls it (checked through `SEQUANT_PHASE`, even with an issue number), when it gets no issue number, or when Claude calls it on its own before a commit. A `/verify <N>` you ask for, and the verify phase, run as before. `sequant update` / `sync` deliver the guard to existing projects. `/upstream` now files changelog lines that name a skill Sequant ships under a new **Name Collision** category instead of No Action, and warns if it cannot find the shipped skill list. See ADR-0009.
