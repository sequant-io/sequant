## Problem

"Cost per run: whose API key, rough tokens or dollars, and whether the separate review session doubles the bill" was the cold reader's blocking question. The product already knows: `.sequant/metrics.json` carries `metrics.costUSD` and `tokensUsed` per run (154 of 420 runs on this checkout, $935.69 in total; the last run $6.45 and 69,641 tokens for three issues), and `sequant stats` prints a phase × model table under "SDK estimate, not a billing statement". It is shown nowhere a user looks after a run. This node surfaces the same record in the run summary, the run log (optional `cost`) and `sequant logs`, with the same wording (I-7). A run with no metrics record says `cost unrecorded`, never `$0.00`.
