## What

Re-run the 2026-10-09 stranger smoke test against a build of `main` after #1386, #1380 and #1387 merge, and confirm the fixes hold end to end for a newcomer.

This proves the fixes work. It does not prove a user receives them: no release can ship during the plugin freeze (graph doc D-1), so they reach users only in the first post-freeze release.

## How

On the private calibration fixture repo: a fresh clone, a branch with Sequant removed, a base branch that is **not** the repo default, `npm pack` of `main` installed into it, `npx sequant init --yes`, `doctor`, commit, one new small issue, then `npx sequant run <N> --base <branch>` launched through `launchctl submit` (never a backgrounded Bash task, #856). Recipe: the 2026-10-09 run in the GTM memory.

## Acceptance Criteria

- [ ] AC-1: The PR the run opens has its base equal to the `--base` branch, and its diff against that base contains only the issue's change. Evidence: `gh pr view <PR> --json baseRefName,files` output pasted in a comment, showing the base and the file list.
- [ ] AC-2: `init`'s next steps tell the user to commit `.claude/skills/` before the first `sequant run`, and no command in the session prints a warning telling a README-following user to uninstall Sequant. Evidence: the captured `init` and `doctor` output pasted in a comment.
- [ ] AC-3: `doctor`'s `Warnings:` count equals the number of `!` lines it printed. Evidence: the captured `doctor` output.
- [ ] AC-4: Every new problem the run surfaces is filed or recorded as not a defect, with a reason. Evidence: a smoke report comment listing each finding with its issue number or reason.
