## Problem

`sequant run <N> --base <branch>` creates the worktree from `<branch>` and rebases onto `origin/<branch>` before the PR, but **opens the PR against the repository's default branch**. The PR's diff then includes everything that differs between `<branch>` and the default branch, not just the issue's change.

**Seen:** stranger smoke test, 2026-10-09, sequant 2.19.0 (npm), Claude Code 2.1.295. `sequant run 21 --base smoke/stranger-2026-10-09` on a private fixture repo: the log says "Preparing worktrees from smoke/stranger-2026-10-09" and "Branch merged origin/smoke/stranger-2026-10-09", but the PR was created with `base=main`. Against its real base the change is 2 files, +161 lines. Against `main` the PR shows 37 files, +6,354/−440, because the base branch held a fresh `sequant init` that `main` did not.

**Cause:** `createPR` sets `fields.base` only from `stackOptions.prBase` (`src/lib/workflow/worktree-manager.ts:2342`). `stackOptions` is built only under `--stacked` / chain mode (`src/lib/workflow/batch-executor.ts:1213`, #605). A plain `--base` (or `settings.run.defaultBase`) never reaches `gh pr create`, which then uses the repo default. #605 and #748 fixed the chain and stacked variants of this class; the non-chain path was not covered.

## Acceptance Criteria

- [ ] AC-1: With `--base <branch>` and no `--stacked`, the PR is opened with `base: <branch>`, and worktree creation, `rebaseBeforePR` and `createPR` all receive the same `ResolvedRun.baseBranch` value. Evidence: a test that runs the issue path with a non-default base and asserts the three consumers got one identical value, mutation-verified by dropping the base from the `createPR` call.
- [ ] AC-2: `settings.run.defaultBase` set to a non-default branch has the same effect as `--base`. Evidence: a test with the setting set and no CLI option.
- [ ] AC-3: With neither `--base` nor `defaultBase`, the PR base is unchanged (the repo default). Evidence: an existing or added test.
- [ ] AC-4: `--stacked` still targets the predecessor branch and takes precedence over `--base` for non-last links. Evidence: the existing #605 tests pass.
