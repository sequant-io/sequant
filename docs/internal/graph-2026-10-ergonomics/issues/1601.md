chore(deps): one weekly grouped Dependabot batch per ecosystem — 20 of 39 Dependabot PRs in 60 days closed unmerged, superseded by regrouped bumps

## Problem

In the 60 days to 2026-10-26, Dependabot opened 39 PRs; 20 closed unmerged because a later run regrouped the same bumps. Three more sat open for four days. Each superseded PR still ran CI (about 8.5 min of the required `test` check) and appeared in the review queue.

## Acceptance Criteria

- [ ] AC-1: `.github/dependabot.yml` declares one weekly schedule per ecosystem with a single `groups` entry covering all dependencies of that ecosystem (patch and minor), so a run opens at most one PR per ecosystem. Evidence: `yq '.updates[] | [.["package-ecosystem"], .schedule.interval, (.groups | length)] | @tsv' .github/dependabot.yml` → every row ends in `weekly` and `1`
- [ ] AC-2: Over the following four weeks, no Dependabot PR closes unmerged as superseded. Evidence: `gh pr list --author app/dependabot --state closed --search "closed:>$(date -v-28d +%F)" --json number,mergedAt --jq '[.[] | select(.mergedAt==null)] | length'` → `0` (measured, lagging)

## Non-Goals

- Auto-merge; that waits for the merge queue (#1368).
