## Problem

Every later node's AC reads a number, and today each number is produced by an ad-hoc script in a session scratchpad (`fnlen.mjs`, grep pipelines). Without a committed script and baseline, "the number went from A to B" is unverifiable and nothing stops it going back up. The repo already has the pattern: `scripts/qa/tautology-detector-cli.ts` plus the `tautology-advisory` CI job.
